# MoneyTree

Money doesn't grow on trees, but now bank deposits can finally branch out.

A free-to-play, gamified sweepstakes demo. Players dig a 100 × 100 grid laid over a tree to find tokenized deposits funded by a bank or credit union, then open an account with that institution to receive them.

**This is a demo.** Clicks, prizes, the sponsor ("Example Credit Union"), account opening and identity checks are all simulated in the browser. Nothing is stored, sent or paid out.

## Run it

Open `index.html` in a browser, or visit the GitHub Pages site for this repository. The page is a single self-contained file; the only external request is for web fonts.

## Configure it

Game settings (grid size, prize amounts, free clicks, sponsor name, share text) live in the `CONFIG` block at the top of the script in `index.html`.
